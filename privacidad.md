# Política de privacidad

Última actualización: 16 de octubre de 2026

Esta política describe cómo la aplicación Hoy Dios te habla Publicador, operada por el equipo del canal Hoy Dios te habla, trata la información cuando se conecta a servicios de Google (YouTube), Meta (Facebook e Instagram) y TikTok.

## Qué hace la aplicación

La aplicación es una herramienta interna que publica y programa los videos, fotos y carruseles del propio canal religioso Hoy Dios te habla en sus cuentas oficiales: YouTube mediante la API de YouTube Data, Facebook e Instagram mediante la API Graph de Meta, y TikTok mediante la Content Posting API de TikTok. Solo la utiliza el equipo del canal, con las cuentas que administra ese canal. No está dirigida al público en general.

## Qué información usa

La aplicación solicita acceso a las cuentas del canal únicamente para subir y programar su propio contenido (videos, fotos, carruseles, títulos, descripciones, miniaturas, portadas y etiquetas) y, en el caso de YouTube, agregar videos a listas de reproducción y publicar comentarios en el propio canal. Ese contenido es creado por el equipo del canal.

## Qué información NO recopilamos

No recopilamos, almacenamos ni procesamos datos personales de visitantes, espectadores, seguidores ni de ningún otro usuario de YouTube, Facebook, Instagram o TikTok. No vendemos, alquilamos ni compartimos información con terceros, y no usamos los datos recibidos de estas plataformas para publicidad.

## Cómo se guardan las credenciales

Las autorizaciones de acceso (tokens) de Google, Meta y TikTok se guardan únicamente en el equipo del canal y no se envían a ningún otro servidor.

## Servicios de YouTube y de Google

El uso de la API de YouTube está sujeto a los Términos de Servicio de los Servicios de API de YouTube (https://www.youtube.com/t/terms) y a la Política de Privacidad de Google (https://policies.google.com/privacy). El uso y la transferencia de la información recibida de las API de Google se apega a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

## Servicios de Meta (Facebook e Instagram)

El uso de las API de Meta está sujeto a los Términos de la Plataforma de Meta (https://developers.facebook.com/terms) y a la Política de Privacidad de Meta (https://www.facebook.com/privacy/policy).

## Servicios de TikTok

El uso de la Content Posting API de TikTok está sujeto a los Términos de Servicio para Desarrolladores de TikTok (https://www.tiktok.com/legal/page/global/tik-tok-developer-terms-of-service/en) y a la Política de Privacidad de TikTok (https://www.tiktok.com/legal/page/row/privacy-policy/en). La aplicación solo publica videos en la cuenta de TikTok del propio canal y no lee información de otros usuarios.

## Cómo revocar el acceso

Puedes revocar en cualquier momento el acceso de la aplicación desde la configuración de seguridad de cada cuenta: Google (https://myaccount.google.com/permissions), Facebook e Instagram (Configuración > Integraciones comerciales) y TikTok (Configuración y privacidad > Seguridad y permisos > Permisos de aplicaciones).
